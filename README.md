# Developer vs Tester — Live Career Scorecard

A single page, fully responsive landing page that turns the classic Developer vs Tester career debate into a cricket stadium style scorecard. Built for Pune based IT learners trying to decide which side of the field to play on, with live interactive JustAcademy training links woven naturally through the page.

## Live Preview

Open `index.html` directly in a browser, or enable GitHub Pages on this repository (Settings → Pages → Deploy from branch → main → root) to get a shareable live link.

## Design Concept

Instead of the usual SaaS card layout, this page borrows the visual language of a night match at a stadium. A floodlit dark background, an amber scoreboard accent, and two rival team colours (developer blue, tester red) run through every section, from the opening scoreboard to the closing verdict box.

Sections include:

- **Match Day Hero** — a scoreboard style VS badge introducing the two teams
- **Playing XI** — side by side player cards with skill stat bars for developers and testers
- **Commentary Box** — short pundit style quotes on how the two roles are converging
- **Salary Innings** — a three over breakdown of how pay evolves from fresher to senior level
- **Training Ground** — sponsor board style cards linking to Pune based JustAcademy courses and bootcamps
- **Press Box** — a further reading list linking to related JustAcademy blog posts
- **Verdict** — a closing call to action with a free demo booking link and the full blog comparison

## Tech Stack

- Semantic HTML5
- Vanilla CSS3 (custom properties, CSS Grid, Flexbox, no framework)
- Google Fonts: Oswald for display headings, Inter for body text
- Zero JavaScript dependencies, zero build step

## Fully Responsive

The layout collapses gracefully from a two column player lineup and four column training grid on desktop down to a single column, thumb friendly layout on mobile, with a lightweight nav toggle on small screens.
